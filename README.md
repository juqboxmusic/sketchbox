# SketchBox 🎨

A friendly drawing, pixel-art and animation app for kids and neurodivergent artists. Big buttons, one shared canvas across freehand Draw and grid-snapped Pixel Art modes, a FlipaClip-style Animate mode with onion skinning, layers, select & move, brush opacity, transparent backgrounds, autosave, a sketch gallery with file backup/restore, and PNG/JPEG export plus animated GIF export (with transparency, for video-editor overlays) — all in one dependency-free HTML file.

**Run it:** open `index.html` in any browser, or serve the folder with any static host.

Sketches are stored in the browser's localStorage, so they stay on the device they were made on.
